# Contributing

Thanks for your interest in helping with Odysseus. It's meant to stay small, so the most useful contributions are issues.

## Reporting a bug

Open an [issue](https://github.com/flourish-today/Odysseus/issues) with:

-   Your phone model and GrapheneOS version
-   What you did, what you expected, and what happened

For security problems, follow [SECURITY.md](SECURITY.md) instead of opening a public issue.

## Verifying a build

If you build a release yourself by following [Reproducible builds](PRIVACY.md#reproducible-builds), please share the result in an issue.

## Pull requests

-   Keep changes small and explain why they're needed.
-   Odysseus won't add permissions, network access, or libraries.
-   New features are unlikely to be accepted unless they fit what Odysseus already does. Open an issue to discuss first.
-   Restricting Owner directly, so Odysseus can be used without a separate daily user, is open for discussion, though it may be better suited to a fork.
