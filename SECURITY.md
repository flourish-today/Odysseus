# Security Policy

Odysseus aims to be a secure app that people can rely on to improve their well being, therefore security is taken seriously to protect the users and all issues will be addressed.

## Reporting a vulnerability

GitHub Private Vulnerability Reporting: https://github.com/flourish-today/Odysseus/security/advisories/new

Email: flourish.today@protonmail.com

SimpleX: https://smp17.simplex.im/a#OYNzLgLMY-vsrI69LroxLrhc4xkyLGpT2Q5ygNvoaAc

## Supported versions and response time

Only the latest release gets security fixes. I aim to reply as soon as I can.
